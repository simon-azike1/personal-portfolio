## Portfolio Overview
This is a modern, responsive portfolio website built to showcase Simon Azike's professional work, skills, and client testimonials.

### Technologies Used
- **Frontend:** React, Vite, Tailwind CSS, Framer Motion, React Router
- **Backend:** Express, Mongoose, Helmet, CORS, compression, rate limiting
- **Database:** MongoDB Atlas
- **Deployment:** 
  - Frontend: Vercel
  - Backend: Node.js host (Render, Railway, or Fly.io)

### Key Features
- Fully responsive design with animated sections
- Dynamic content loading from REST API (projects, skills, testimonials)
- Multilingual support (English and French)
- Light and dark theme toggle
- Vercel-ready frontend build
- MongoDB persistence for all portfolio data
